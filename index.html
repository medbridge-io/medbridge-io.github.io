WHY MEDBRIDGE

"과학은 아는데,
영어로 설명을 못 합니다."

유럽 의대 입시와 면접의 진짜 관문은 지식의 양이 아닙니다. 아는 것을 영어로, 면접관 앞에서, 조리 있게 말하는 능력입니다. 단발성 수업으로는 자라지 않습니다 — 기초 → 정의 → 설명 → 논증으로 이어지는 경로가 필요합니다.

📚

단어는 외웠지만 문장이 안 나온다

용어는 알지만 "그래서 그게 무엇인지" 한 문장으로 설명하지 못합니다. 면접에서는 단어가 아니라 설명이 필요합니다.

🤐

아는 내용 앞에서도 입이 멈춘다

한국어로는 술술 말할 내용을, 영어로 바꾸는 순간 침묵합니다. 구조가 없으면 유창함은 오지 않습니다.

🧩

생물·화학이 따로 논다

단편적으로 외운 지식은 면접의 꼬리 질문에 무너집니다. 분자 하나를 생물과 화학 양쪽으로 설명할 수 있어야 합니다.

🎤

실전 발표·논증 경험이 없다

혼자 공부한 학생은 "소리 내어 끝까지 설명하고, 왜 중요한지 논증한" 경험이 없습니다. 면접은 말하기 훈련의 결과입니다.

MedBridge 101은 이 네 가지를 가장 먼저 해결합니다 — 실제 영어 기사로 어휘·발음·말하기 구조를 다지고, 모든 토픽을 PREP 구조의 면접 답변으로 마무리하며, 자신감 있게 말하는 습관을 만듭니다. 그 위에서 MedPath가 "무엇 → 어떻게 → 왜"의 과학 말하기를 쌓습니다.
모든 길은 단단한 기초에서 시작됩니다.
THE COMMUNICATION OUTPUT LAYER

암기가 아니라, 말하기.

INPUT → OUTPUT

출력의 힘

기존 교육은 암기·독해·문제풀이 같은 Input에 집중합니다. 그러나 면접·토론·발표에서 필요한 건 생각을 실시간으로 구조화해 표현하는 Output입니다.

LYVON = LIVE ON

평생 남는 자산

시험을 위해 외운 영어는 잊힙니다. 사고하고 표현하는 능력은 학생의 평생 자산이 되어 — 의대 이후에도 계속 살아남습니다(Live On).

PREP FRAMEWORK

구조가 유창함을 만든다

주장(Point) → 근거(Reason) → 예시(Example) → 정리(Point). 모든 답변을 이 구조 위에 훈련해, 막힘없는 면접 스피킹으로 완성합니다.

HOW THE CURRICULUM WORKS

읽고 토론한다. 그리고 면접처럼 답한다.

30개 토픽 전체에서 방식은 일정합니다 — 실제 뉴스를 읽고, 그것에 대해 말하고, 면접처럼 답합니다. 모든 토픽은 두 개의 기둥으로 구성됩니다.

PILLAR 1

토픽 유창성

어휘 · 이해 · 토론 — 읽고 토론하기

매 레슨은 건강·과학·사회를 다룬 실제 영어 기사로 시작합니다. 주제별 핵심 어휘를 쌓고, 내용을 이해한 뒤, 기사를 소리 내어 토론합니다 — 묵독을 영어 말하기로 바꿉니다.

PILLAR 2

면접 준비

적용 질문 · PREP 구조 — 답하기 위한 말하기

모든 토픽은 실제 의대 면접 질문으로 마무리됩니다. 학생은 PREP 구조(주장 → 근거 → 예시 → 정리)로 답변을 구성하고, 발음·유창성·전달력 코칭을 받습니다.

SESSION STRUCTURE

모든 세션은 같은 50분 흐름.

30개 토픽 전체에 동일하게 반복되는 하나의 구조입니다 (주 4회 기준).

시간단계진행 내용
5분① 워밍업오늘의 단어 3개와 발음 연습 — 학생이 영어로 말문을 엽니다.
7분② 어휘핵심 단어와 표현, 정의와 짧은 예문 — 외우기가 아니라 말할 준비.
10분③ 읽기·이해기사 읽기와 빠른 이해 점검 — 말하기로 곧바로 이어가는 입력 확보.
15분④ 가이드 토론PREP 구조를 적용한 질문 중심 토론, 문장 교정과 핵심 표현 반복.
10분⑤ 적용 말하기의대 면접 질문에 PREP로 실제 답변 구성, 유창성·전달력 코칭.
3분⑥ 마무리핵심 정리, 기억할 표현 하나, 다음 세션 예고.

VOCABULARY

어휘

매 세션, 한 걸음 더 깊이.
